## Routing Rules

При создании или поиске заметки определяй папку по теме:

1. **Работа, коллеги, 1-1, проекты RC** → `RingCentral`
2. **Здоровье, врачи, лекарства, анализы** → `BG/Здоровье`
3. **Машина, СТО, штрафы, дороги** → `BG/Авто`
4. **Болгария, сервисы, контакты в БГ** → `BG`
5. **Технические шпаргалки, CLI, DevOps** → `Dev Notes`
6. **Инвестиции, портфель, ETF, накопления** → `Investments`
7. **Резюме, карьера, LinkedIn** → `Resume`
8. **Orgfin проект** → `Orgfin.run`
9. **Бот, Claude Code, Krokobot** → `Krokobot`
10. **Слава (сын)** → `Slava`
11. **Грин-карта, иммиграция США** → `US Green Card`
12. **Еда, рецепты** → `Еда`
13. **Стихи** → `Poems`
14. **TODO, главная** → `_Dashboard`
15. **Всё остальное (аккаунты, пароли, личное)** → `General`

## Attachments — per-folder rule

**`_attachments/` живёт внутри той же папки, где лежит .md-заметка, ссылающаяся на вложение.** Это конвенция данного vault'а: каждая папка с заметками может иметь свой `_attachments/` рядом с .md-файлами. Никаких единых "_attachments на весь раздел" не делаем.

### Правило в одну строку

> Создаёшь/перемещаешь .md, который тянет вложение через `![[file.jpg]]` или `[[file.pdf]]` — `_attachments/` создаётся (или используется существующий) **в той же директории**, где лежит сам .md.

### Пример

```
Health/
├── Анализы/
│   ├── Анализ 2026-02-07.md
│   └── _attachments/                ← вложения, на которые ссылается Анализ 2026-02-07.md
├── Консультации/
│   ├── Флеболог 2026-04-23.md
│   └── _attachments/                ← вложения визита (фото с УЗИ-снимка и т.п.)
└── Операции/
    ├── Операция X 2026-04-03.md
    └── _attachments/
```

**Не так:**

```
Health/
├── _attachments/                    ← ❌ единый "склад" на верхнем уровне Health/
├── Анализы/
└── Консультации/
    └── Флеболог 2026-04-23.md       ← .md в Консультациях, вложения в корне — ссылка резолвится Obsidian'ом, но раскладка ломается
```

### Когда переносишь .md между папками

Если файл ссылается на вложение через `![[name.ext]]`, при переносе .md в другую папку **либо** перенеси соответствующее вложение в `_attachments/` целевой папки, **либо** убедись что вложение уже есть там. Без этого ссылка не сломается (Obsidian резолвит по имени), но раскладка перестаёт следовать конвенции.

### При создании новой подпапки с заметками

Если в новой подпапке заметки начнут ссылаться на вложения — создаём `<подпапка>/_attachments/` рядом. Не лей в чужой `_attachments` "потому что там уже есть".

## Search Strategy

1. Сначала ищи в целевой папке по теме (Routing Rules выше)
2. Если не нашёл — Grep по всему vault
3. Для поиска по имени — Glob `~/obsidian-vaul/**/*keyword*.md`
4. Для поиска по содержимому — Grep pattern в `~/obsidian-vaul/`
